# Goals and Non-goals

## 初心（Problem Statement）

B 站有大量高质量但很长的视频，阅读效率低。VideoSieve 要把“语言/字幕 + PPT/关键画面”中的核心信息提取出来，形成可快速消费、可追溯的知识资产。

## Goals

- 自动生成可读转译稿（去口语、断句、保真）
- 生成带证据链的图文交错笔记（关键帧 + FrameSummary + 时间对齐）
- 生成 100-500 字摘要与标题
- 支持多个项目排队与同时查看、实时日志、进度、暂停/继续/取消/删除

## Non-goals (Current Phase)

- 复杂多租户权限体系
- 多计算节点调度和高可用集群
- 向量检索/全文检索平台能力
- 对所有视频类型做到完美抽帧

## Scope Boundary

- 优先保证工程稳定、可观测、可复现
- 当前固定为单机 SQLite + 独立 worker；只有测量到扩展需求后才重新选型
